> - **§2B.2 Burmese Dictionary** — MM badge, concept ဘာသာပြန်
> - ~~§2B.4 Token Budget Meter~~ — **ဖြုတ်ပြီး**: token ကန့်သတ်ချက် မရှိ၊ prompt ကို ဘယ်တော့မှ မဖြတ် (ရွေးစရာ အကုန်ရွေးလည်း အပြည့်ရောက်) · AI refine ကလည်း မတိုစေ
> - **§2B.3 Reverse** — device-side image measurement (mock မဟုတ်)
> - **§2B.7 Prompt Git** — save · branch · **word-level diff**
> - **§1.11 Grade** — tone · colour · monotone curves · live histogram + clip warning ·
>   The Reveal ဖြင့် stage scrub · full-res JPG · **`.cube` LUT export** · looks (built-in ၄ + own)
>
> - **Studio catalogue ချဲ့** (2026-10-01) — ရွေးစရာ ~၁၇၅ → **~၉၆၀** · group အသစ်: ကင်မရာ · မှန်ဘီလူး · aperture · ရိုက်ထောင့် · composition · အချိန် · ရာသီဥတု · မျက်နှာအမူအရာ · ဟန် · ဆံပင်/မိတ်ကပ် · လက်ဝတ်ရတနာ · နောက်ခံ · props · garnish · mood · အလင်း ၁၈ မျိုး + film/grade ၁၈ မျိုး အကုန်မှာ · ရှာဖွေ box (EN/MY) · group တစ်ခုချင်း "+ နောက်ထပ်"
> - **Refine with AI** = `openai/gpt-4.1` (OpenRouter)
> - **Edit-first** (2026-10-01) — Studio မှာ **ပြင်မယ့်ပုံ (image 1) + reference ပုံ ၆ ပုံ** (role ၁၀ မျိုး + မှတ်ချက်) · "မပြောင်းစေချင်တာ" (မျက်နှာ/ဟန်/နောက်ခံ…) · prompt က image နံပါတ်နဲ့ ("Edit image 1 … From image 2, take … From image 1, keep …") · Image ထုတ်မည် → Create က edit mode နဲ့ ပုံတွေပါ တန်းဖွင့်
> - **The Reveal ပြင်** — ပုံ ၂ ပုံ ယှဉ်ရင် After|Before label အမြဲပြ · လွှတ်တဲ့နေရာမှာ ရပ် (snap မလုပ်) · ⤢ / double-click → fullscreen viewer · wheel/pinch zoom ၈၀၀% · zoom ထားရင် ဆွဲ = pan · handle ကို ဆက်ဆွဲလို့ရ · room တိုင်းရဲ့ model ရလဒ်ကိုလည်း မူရင်းနဲ့ slider ယှဉ်ပြ
> - **§1.12 Batch** — look apply · **Series Coherence** + per-frame fix · auto-cull (soft/clipped/burst) · folder pick · .zip
> - **§1.10 Restore** — dust · scratches · fade/cast · tone · sharpen (device) · repaired-pixel proof · colourise (ဝတ်စုံအရောင် ရွေး) / faces / rebuild / **§2.1 Living Memory** (premium)
> - **§1.8 Harmonize** — **AI-first** (2026-10-01): ပုံ ၁ = နောက်ခံ, ပုံ ၂ = လူ (cut-out မလို) → model က နေရာချ + အလင်း/အရိပ် ညှိ · မျက်နှာ ပုံ ၂ ကနေပဲ (🔒) · ဝတ်စုံ/ဟန်/ဆံပင်/အမူအရာ ထိန်း · "AI ရွေး" သို့ "ကိုယ်တိုင် နေရာချ" · before/after slider · **§2.2 Family Reunion** · ဒုတိယ tab "ဖုန်းပေါ်မှာ · အခမဲ့" = mode ၁၂ · effects slider · pixel-lock · ၄ မျိုး ရွေး

## 2B.1 ★★★ Prompt Compiler — generator မဟုတ်၊ **compiler**

ဆုံးဖြတ်ချက်တွေကို **IR (intermediate representation)** အဖြစ် သိမ်းပြီး၊ target အလိုက် **dialect ထုတ်**တယ်။ Compiler တစ်ခုလို — source တစ်ခု, backend များစွာ။


## 2B.2 ★★★ Burmese Prompt Dictionary — မြန်မာစကားလုံးကို model နားလည်အောင်

**ပြဿနာ:** AI model တွေ မြန်မာ concept တွေကို **လုံးဝ မသိဘူး**။
`လုံချည်` `ပုဆိုး` `သနပ်ခါး` `အင်္ကျီ` `ခေါင်းပေါင်း` `ကျောက်ကပ်` `ရိုးရာ` `ခန့်ညား` `အေးဆေး` `ငြိမ့်ငြိမ့်` — prompt ထဲ ထည့်လိုက်ရင် **ဘာမှ မဖြစ်ဘူး**။

**ဖြေရှင်းချက်:** မြန်မာ concept → model နားလည်တဲ့ **visual descriptor** အဖြစ် ပြန်ဖြေ
```
"လုံချည်"  → "longyi, ankle-length wrapped sarong, single front pleat knot,
              woven cotton, natural drape"
"သနပ်ခါး"  → "thanaka, pale golden-cream bark paste applied in two soft
              circular patches on the cheeks, matte texture"
"ခန့်ညား"  → "composed, upright posture, restrained expression,
              formal Southeast Asian portrait bearing"
```
- Concept **၅၀၀+** (ဝတ်စုံ, ပစ္စည်း, ပွဲလမ်း, ခံစားချက်, နေရာ, အလင်း)
- Model အလိုက် တိုက်ဆိုင်စစ်ထား (Flux က နားလည်တာ, MidJourney က နားလည်တာ မတူ)
- **ဒါက စာသား ဘာသာပြန်တာ မဟုတ်ဘူး — concept ဘာသာပြန်တာ**

**★ Burmese voice input** — ပြောရုံနဲ့ prompt ဖြစ်

## 2B.4 ★★ Token Budget Meter — ရှိမှန်းလူမသိသေးတဲ့အရာ

## 2B.5 ★★ Token Ablation — "ဒီစာလုံး ဖြုတ်ရင် ဘာဖြစ်မလဲ"

Prompt ထဲက စာလုံး/စကားစုတစ်ခုချင်းကို **တစ်လှည့်စီ ဖျောက်ပြီး** ရလဒ် ဘယ်လောက်ပြောင်းလဲ တိုင်းပြ။

```
"cinematic lighting"     ██████████  ရလဒ်ကို 34% ပြောင်း  ← အရေးကြီး
"8k, ultra detailed"     ▏           ရလဒ်ကို  1% ပြောင်း  ← အလကား ဖြုတ်လိုက်
"golden hour"            ███████     ရလဒ်ကို 22% ပြောင်း
```

**ဘာလို့ novel လဲ:** လူတွေ prompt ကို **အယူသီးမှုနဲ့** ရေးနေတာ — "8k, masterpiece, ultra detailed" ထည့်ရင် ကောင်းတယ်ဆိုပြီး။ တကယ်က ဘာမှ မဖြစ်ဘူး။ **ဒါကို သက်သေပြပေးတဲ့ tool ကမ္ဘာမှာ မရှိသေးဘူး။**

## 2B.6 ★★ Model Arena — prompt တစ်ခု, model ၆ ခု, တစ်ချက်တည်း

တူညီတဲ့ prompt ကို model ၆ ခုမှာ တစ်ပြိုင်တည်း run → grid နဲ့ ပြ → Reveal slider နဲ့ နှိုင်းယှဉ် → ကြိုက်တာရွေး
- ဘယ် model က ဘယ်အလုပ်မျိုးမှာ ကောင်းလဲ **ကိုယ်တိုင် မြင်ရ**
- Cost ကို model အလိုက် တစ်ခါတည်း ပြ

## 2B.7 ★ Prompt Git (§3.5 ရဲ့ prompt ဘက်)
- Prompt တစ်ခုချင်း **branch / diff / merge**
- Prompt ↔ ရလဒ် ချိတ်ထား — "ဒီ prompt က ဒီပုံ ထုတ်ခဲ့တာ"
- **Word-level diff** — prompt ၂ ခုကြား ဘာပြောင်းလဲလဲ highlight
- Seed pin → ပြန် run ရင် တူတူ

## 2B.8 ★ Prompt Library / Marketplace
မြန်မာမှာ prompt ရောင်းတဲ့ FB group တွေ ရှိပြီးသား — SHOW မှာ တရားဝင်လုပ်
- Prompt တင် → **ရလဒ်ပုံနဲ့တကွ** → ရောင်း → revenue share
- **Verified badge** — SHOW က တကယ် run ပြီး ရလဒ်ထွက်မှ ✓
- Category, model tag, ဈေးနှုန်း, rating
- ကိုယ်ပိုင် prompt တွေကို private collection အဖြစ်လည်း သိမ်းလို့ရ

## 2B.9 ★ Syntax Tutor (မြန်မာလို)
- MidJourney `--ar --sref --cref --style --raw --chaos --weird` — မြန်မာလို ရှင်းပြ + auto-insert
- Weight `(word:1.3)` / `[word:0.8]` — slider နဲ့ ချိန်ရုံ, syntax မမှတ်ရ
- **Negative intelligence** — model အလိုက် negative မတူ (Flux က negative မလို, SDXL က လို) → auto-adapt
- **--sref manager** — style reference code တွေ စု, အမည်ပေး, preview နဲ့ သိမ်း

# PART 3 — Architecture & Signature Interaction

## 3.1 ★ The Reveal — SHOW ရဲ့ signature (AJAX slider ရဲ့ ဆင့်ကဲပုံ)
Slider ဆွဲရင် before↔after နှစ်ခုတည်း မဟုတ်ဘဲ **layer stack တစ်ခုချင်း ဖြစ်ပေါ်လာတာ** မြင်ရ:
```
မူရင်း → အရိပ် solve → အလင်း solve → အရောင် grade → အသားအရေ → ပြီး
```
တစ်လက်နဲ့ (mobile-first)။ §3.6 The Negative ရှိလို့ ဖြစ်နိုင်တာ — **copy လုပ်လို့ မရဘူး**

## 3.2 ★ Light Sculpting
Depth + normal map ပေါ်မှာ **လက်နဲ့ အလင်း ဆွဲရွှေ့** — physical falloff + soft shadow real-time (WebGPU), ဖုန်းပေါ် ၆၀fps

## 3.3 ★ The Wait
AJAX က particle ပြတယ်။ SHOW က **film develop သဘော** — ပုံ တဖြည်းဖြည်း ပေါ်လာ၊ ဆွဲကြည့်လို့ရ။ စောင့်ချိန်က experience ဖြစ်ရမယ်

## 3.4 ★ Task-first IA (room ၁၇ ခု browser မဟုတ်)
Feature အားလုံး ရှိတယ် — ဒါပေမယ့် **ဖော်ပြပုံ မတူ**:
- **Fast lane** — "ဘာလုပ်ချင်လဲ" ၈ ခု → တစ်ချက်နှိပ် → ရလဒ် ၄ ခု (၁၅ စက္ကန့်)
- **Deep lane** — ရလဒ်ကနေ ဆက်ပြင်ချင်ရင်မှ control အပြည့် ဖွင့်
- Room ကို အစကနေ ဖြတ်ခိုင်းတာ **မလုပ်ရ**

## 3.5 ★ Photograph Git
Generation တိုင်းက node → **branch / semantic diff / merge**
- "ဒီ branch က light 40% ပြောင်း, identity 2% ပြောင်း"
- Client က branch ၂ ခုကို Reveal slider နဲ့ နှိုင်းယှဉ်ရွေး
- Seed + model version pin → ပြန် run ရင် တူတူ

## 3.6 ★ The Negative — semantic layer model
Ingest ချိန်မှာ ပုံကို layer ခွဲ: `subject · skin · hair · eyes · garment · jewelry · ground · background · light · atmosphere · grain`
Layer တစ်ခုချင်း addressable/re-generatable/lockable
Output = "develop" (story / print / album / web တစ်ခုချင်း negative ကနေ)

→ **§3.1, §3.2, §3.5, §1.12 Series Coherence အားလုံးရဲ့ အခြေခံ**

## 3.7 ★ Edge Runtime (Rust → WASM + WebGPU)
Server နဲ့ browser တစ်ခုတည်းသော codebase → **pixel-identical**
Offline: crop, grade, curves, retouch, cutout, batch, export
CRDT sync on reconnect
